# Design Decisions --- Evidence System & Component Data Model

Decision log from the grilling sessions behind `docs/adr/DATA_MODEL_SPEC.md`. Philosophical precedent:
M. Bernhard, *HYBREP* (`reference/Bernhard_HYBREP.pdf`) --- referenced, not adopted as a name.
Regulatory reference: Regulation (EU) 2024/3110 (`reference/CPR_2024_3110.pdf`), analysed in the spec section 10.

**Started:** 2026-09-10 ; **Updated:** 2026-09-30 ; **Status:** 1.1--8.22 decided; open topics O1--O2 below; consolidated into `docs/adr/DATA_MODEL_SPEC.md`, which is now authoritative.

**Calibration:** research prototype; user-facing breakage is acceptable. Optimise for
correctness and best practice, not migration cost. Recommendations that hedge toward minimal
change are wrong by default.

## 1. Evidence system (supersedes parts of the 0.5 measurements draft)

"Spec section" numbers in 1.x point at that draft (2026-09-09), retired 2026-10-02; what it held
that still matters is in `DATA_MODEL_SPEC.md` (section 2.5, Appendix A.0, Sources).

| # | Decision | Consequence |
|---|---|---|
| 1.1 | **Purpose: documentation of record.** A recorded measurement is auditable evidence you could point at to justify reusing a piece. | Raw readings preserved; named responsible bodies; lab PDFs first-class; admin validation. |
| 1.2 | **Snapshot context is always recomputed, never stored** on the record. | Kills `snapshot_id_cached` and its index (spec section 5.4, section 11.1). Cross-catalog analytics cannot filter by snapshot context in the query layer. |
| 1.3 | **Granularity: one record = one test location / one specimen.** Three rebound areas on a panel = three records. | Aggregation is read-time. ~~Optional `campaign_id` for grouping~~ --- dropped (7.2). |
| 1.4 | **Detail card shows range + count, never a single headline value.** `34.1--41.2 MPa (n=4)`. | `GET .../measurements/summary` ("latest per quantity") is dropped. A characteristic value is an explicit separate act. |
| 1.5 | **Destructive test: the measurement *is* the event.** No snapshot is created for a core hole. | `SnapshotGeometry` ">=1 representation" invariant untouched. `caused_snapshot_id` dropped from spec section 8. Timeline endpoint (section 10.6) becomes load-bearing. `specimen_identity_id` escape hatch effectively dead. Viewer needs a "destructive tests recorded after this snapshot" flag. |
| 1.6 | **Rename: `component_measurements` --> `component_evidence`.** Measurements are one `method` kind; `archival_document`, `visual_inspection`, `era_heuristic`, `manufacturer_datasheet` are others with small payloads. | Envelope unchanged (identity, time+precision, `performed_by`, `recorded_by`, `summary`, `validated`, supersession). One list, one timeline, one validation queue. The word "measurement" in the spec is wrong in ~40 places. `main_fastapi.py:90` binding is unused, rename is free. |
| 1.7 | **Moderation != verification.** Evidence gets two orthogonal fields: `status: draft\|pending\|published\|rejected` (moderation, admin/moderator; replaces `validated`) and `verification: {state: unverified\|self_attested\|reviewed\|accredited, by, at}` (epistemic; feeds the fold as a confidence factor 0.7 / 0.85 / 1.0 / 1.0). See 1.9. | Only `published` lists by default / enters the fold. Needs a `reviewer` permission *(decided 6.5: per-dataset role; who sets which state: 8.12)*. |
| 1.8 | **Corrections: supersede, don't edit.** Result-bearing fields freeze on publish; a correction is a new record with `supersedes`, old one gets `superseded_by`, drops out of default lists and the fold. Notes / attachments / verification stay editable --- *attachments amended by 7.3: add-only after publish.* | List queries default `superseded_by: null`. No audit subsystem. |
| 1.9 | **Snapshots adopt the same `status` lifecycle; `validated` is dropped.** Promotion (`current_snapshot_id`) stays a separate act. One `draft|pending` snapshot per identity. No `verification` on snapshots. | Migration `true-->published`, `false-->pending`. `/validate` --> `/publish?promote=1`; `/pending-validation` --> `/pending`; GH default filter becomes `status=published`. |

## 2. Property descriptors (Bernhard: instrument 3)

| # | Decision | Consequence |
|---|---|---|
| 2.1 | **A descriptor `{range, confidence, source}` is derived from evidence, never hand-edited.** | Measurements + non-instrumental claims are the inputs. Confidence cannot exist without a record behind it. |
| 2.2 | **Home: `identity.properties`, materialized, recomputed synchronously on any evidence create/validate/supersede/delete.** Pure function of stored inputs, so staleness is impossible by construction (unlike a cached snapshot pointer, hence not in tension with 1.2). | Indexable / filterable by confidence threshold. Follows the `snapshot.descriptors` precedent. |
| 2.3 | **Layering:** intrinsic scalars --> identity; spatial *fields* (strength map, corrosion map) --> snapshot geometry alongside deviation maps (deferred); evidence bridges both via `position` pinned to one snapshot frame. State-dependent quantities: see 2.8. "As of snapshot vN" = fold only evidence with `observed_at <= vN window`, computed on request. | |
| 2.4 | **Split inheritance:** a child identity with no own evidence inherits the parent's derived properties with `source: inherited` and `confidence x k`, k ~ 0.8 (policy constant, same tier as `factor` params in `descriptor specs.py`). Compounds across chained splits. Own evidence displaces inherited values. | Makes never-tested children visible to a "schedule further testing where confidence < x" filter. |
| 2.5 | **Fold rule: highest source tier present wins outright.** Range = min..max of that tier's values widened by per-record uncertainty; confidence = tier base x count scaling. Lower-tier evidence shown as "superseded by evidence", not folded *(renamed 8.2: outranked)*. | No interval intersection, no weighted union. |
| 2.6 | **Tier order is per-quantity**, carried by the quantity vocabulary. Default: destructive > NDT > archival > visual > heuristic. Visual is primary for spalling/cracking; NDT (GPR) beats archival for rebar. | |
| 2.7 | **`condition` is dropped.** Visual state is evidence (`visual_inspection` records with `spalling`, `cracking`, ...); the UI badge is computed from the fold. The 697 legacy grades migrate into evidence records (`quantity: condition_grade`, tier visual, unverified) rather than being discarded. *Amended by 7.9: 698 of 701 grades are a batch default (`2`) and are dropped; only varying grades migrate.* | Removes the last authored-vs-derived duplication. Filters/sort on `condition` go. |
| 2.8 | **Per-quantity scope, two fold targets.** Each quantity declares `scope: identity \| snapshot`. Identity-scoped (strength, density, rebar, mass...) fold from all published evidence into `identity.properties`. Snapshot-scoped (spalling, cracking, corrosion, moisture, carbonation, `condition_grade`) fold from the *as-of* set --- evidence whose resolved context is that snapshot --- into `snapshot.properties`, materialized. Same function, different input filter. | Snapshot fold also reruns on any `effective_from` change in the chain. A fresh snapshot starts with empty state properties until inspected. |

## 4. Classification axes

| # | Decision | Consequence |
|---|---|---|
| 4.1 | **Replace flat `type` with two orthogonal axes.** `type` currently conflates shape (panel, beam), function (connector), and state (rubble). | Breaking change to filters, GH userobjects, wizard, map. Accepted. |
| 4.2 | **`identity.original_function`** in IFC element class *names* (`IfcBeam`, `IfcColumn`, `IfcSlab`, `IfcPlate`, `IfcWall`, `IfcMember`, `IfcPipeSegment`, `IfcFooting`, `IfcDiscreteAccessory`, `IfcBuildingElementProxy` = unknown) + one CSC value for debris with no prior function. **Vocabulary only --- no IFC structure** (no `IfcRelAggregates`, no PSet ceremony, no ownership history). Named `original_` because reclaimed elements' reuse function is a *design* decision and lives on the design, not the piece *(7.11: designs left CSC --- the reuse function lives in design tools outside the catalog)*. | IFC export is a projection. Needs a display-label map. |
| 4.3 | **`snapshot.shape_class`** in `{linear, planar, block, irregular, composite}`, **derived** per snapshot from PCA extent ratios + the four `*score` descriptors with documented thresholds, stored with `shape_class_source: derived\|assigned`, user-overridable. `composite` is always assigned. Drives default proxy, fit method, allowed source representations, applicable descriptors. | Thresholds tuned against the 697 real pieces. |
