# CSC Backend Constraints
# Upper bounds that are not about compatibility with CSC code, but with the server.
#
# Uberspace 7 runs CentOS 7 with glibc 2.17. The newest releases of the packages
# below only ship manylinux_2_28 wheels (glibc >= 2.28); without these caps pip
# picks their source archives and tries to compile them on the server. Each cap
# is the last release with a manylinux2014 (glibc 2.17) wheel for CPython 3.13
# (checked 2026-09-28 with `pip download --only-binary=:all:`).
#
# Lift them when the backend moves to Uberspace 8 (design decision 6.12).
# Verify after any change: `invoke check-server-wheels` (fails if pip would
# need to compile anything on the server).
#
# Install with: pip install -r requirements.txt -c constraints.txt
